# Site de Adna Barbosa

Página pessoal de Adna Barbosa, escritora e educadora: livros, cursos, vídeos, podcast, palestras e contato.

- `index.html`: o site (página única)
- `capas/`: capas dos livros e foto
- `propostas/`: página de comparação de propostas de nome e estética (rascunho, fora dos buscadores)
